# HayDevVPN

[Tor-вкладки, VPN для Windows и границы покрытия](windows-network-routing.md).

Откройте **HayDevVPN**, выберите страну и нажмите **Подключить**.
При первом использовании вместо подключения появится **Войти в Mozilla**.
После входа браузер обнаружит аккаунт автоматически. Пароль вводится в интерфейсе провайдера.

Папку данных, локальные адреса и запуск компонента браузер определяет самостоятельно.
Выбор страны сохраняется провайдером между запусками. В списке отображаются страны,
полученные от провайдера; доступность стран зависит от его списка серверов.

После подключения откройте нужный адрес кнопкой **Открыть VPN-вкладку**.
Этот режим действует на созданные здесь вкладки. Обычные вкладки сохраняют свой маршрут.
Для смены страны отключите VPN; при отключении VPN-вкладки закрываются.

Сетевое соединение проверяется перед открытием VPN-вкладок. При недоступности прокси
эти вкладки не переходят на прямое соединение. Если провайдер сообщает несовпадение
выбранной страны и страны выхода, интерфейс показывает ошибку и блокирует новые соединения.

Браузер запускает включённое в сборку ядро Arman VPN 1.0.13 как отдельный процесс,
с проверкой SHA256, локальным API и закрытием при выходе. Чужой процесс провайдера
не завершается. Если провайдер уже управляет системным VPN, подключение из браузера
останавливается с объяснением. Токены локального API и данные аккаунта не передаются
в React-интерфейс и не включаются в отчёты проверок.

Arman VPN — независимый проект: <https://github.com/armanlife/arman-vpn-client>.
Вход и доступ к серверам обслуживает провайдер. Отказ Mozilla при авторизации
(в том числе HTTP 406) остаётся внешней ошибкой и не означает рабочий туннель.
