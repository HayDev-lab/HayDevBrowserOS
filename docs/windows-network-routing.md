# Маршрутизация HayDev Browser OS в Windows

| Режим | Маршрут | Граница |
| --- | --- | --- |
| Обычная вкладка и оболочка | Маршрут Windows по умолчанию | Настройки Arman и Tor не меняют этот маршрут |
| Приватная вкладка | Отдельный профиль WebView2 и настройка исходящего маршрута профиля | По умолчанию используется Tor при доступности. Для обязательного Tor нужен строгий режим профиля |
| Вкладка Arman | Отдельная InPrivate-среда, SOCKS5 через локальный ретранслятор и Arman | Требуется доступ провайдера Mozilla. TCP-вкладки открываются из HayDevVPN. Для остальных процессов действуют их собственные маршруты |
| Tor-вкладка | Отдельная InPrivate-среда, локальный ретранслятор и встроенный Tor | TCP для HTTP(S), включая TCP-транспорт WebSocket и загрузок. WebRTC и QUIC отключены в проксируемой среде, включая вложенные страницы. Сетевые запросы агента, поиска и других приложений вне режима |
| VPN для Windows | Официальный Proton VPN Free с Advanced kill switch и выключенным split tunneling | Управление и блокировка выполняются клиентом и драйвером Windows. HayDevVPN показывает два локальных выбора интерфейса и ссылки настройки |

Tor-вкладка открывается после подтверждения TCP-соединения через встроенный Tor. Локальный SOCKS-ретранслятор сохраняет свой порт. Каждый новый поток проверяет владельца соединения с Tor. Когда Tor недоступен, ретранслятор возвращает отказ и WebView2 не получает запасной прямой маршрут. Процесс Tor соединяется с узлами Tor по обычному маршруту Windows. Это необходимое исключение для работы прокси.

Локальные компоненты запускаются по запросу. Защищённая вкладка Tor открывается после готовности прокси. Поисковые компоненты запускаются при обращении к HayDev Search или инструменту поиска Research.

Tor доступен без аккаунта. Обычные Tor-вкладки предназначены для сайтов HTTP(S). Для .onion остаётся раздел DarkWeb. Его поиск, включая Ahmia и Tor66, требует готовый SOCKS-маршрут. HTTPS-зеркало Ahmia также используется через Tor. Tor-вкладка использует WebView2 и его собственный отпечаток. Для свойств анонимности Tor Browser нужен официальный Tor Browser. [Рекомендации Tor Project](https://support.torproject.org/tor-browser/general/tor-browser-with-other-browser/)

## Приёмка системного режима

1. На выделенном Windows-хосте установить официальный Proton VPN и войти в тестовый аккаунт Free. Сохранить активные маршруты IPv4/IPv6 и DNS интерфейсов до теста.
2. Включить Advanced kill switch, выключить split tunneling, подключиться и проверить IPv6 отдельно. Действия выполняются в официальном клиенте. [Инструкция Proton](https://protonvpn.com/support/what-is-kill-switch), [IPv6](https://protonvpn.com/support/prevent-ipv6-vpn-leaks)
3. В HayDevVPN нажать **Проверить маршруты Windows**. IP Helper показывает интерфейсы для 1.1.1.1 и 2606:4700:4700::1111 без отправки пакетов. Подтвердить маршрутизацию DNS, TCP и UDP захватом на физическом и туннельном интерфейсах.
4. Проверить IP, DNS A/AAAA, WebRTC/STUN, QUIC, WebSocket и загрузки. Повторить запросы из Rust, SearXNG и независимого приложения Windows. Проверить отключение, аварийную потерю связи, повторное соединение, смену сети, сон, перезапуск и выход.
5. В захвате учесть транспорт туннеля, loopback-соединения и служебные кадры физического интерфейса. Состав исключений берётся из наблюдаемых правил клиента и пакетов.
6. Выключить Advanced kill switch, отключить Proton VPN и сверить исходные маршруты и DNS. Проверить соединение браузера и независимого приложения.

До выполнения этих проверок системный режим остаётся внешней настройкой с неподтверждённым покрытием. Выбор интерфейса по таблице маршрутов показывает только результат локального поиска маршрута.
